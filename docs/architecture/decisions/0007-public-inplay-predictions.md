# ADR 0007: Public in-play predictions

- Status: accepted by explicit owner instruction
- Date: 2026-10-06

## Context

The owner requested: "Also set the in-play predictions to be public. Users
shouldn't be logged in to see them." This supersedes earlier product requirements
that made the prediction fields on the in-play surface a sign-in or paid feature.

## Decision

The deployed API explicitly enables `InPlayPublicRead`. Anonymous readers receive
published in-play prediction fields through the same serializer as other readers
on fixture lists, fixture details, overview, changes and the stream. This viewer
is a publication policy, not an authenticated account or an entitlement to any
other feature. Account and administrator authorization is unchanged.

The public web does not wait for account resolution or show a login/subscription
offer before rendering in-play content. Unavailable data is still unavailable:
source suppression, stale labels, suspended figures, request limits, cache
protections and stream pacing remain in force. No data is generated by a public
request, and no additional provider calls are authorized by this change.

## Verification and consequences

Keep the existing permanent gated-policy invariant suite unchanged. New ordinary
HTTP tests verify the public policy across every in-play route, suppression,
method restrictions and private-route isolation; a composition test verifies the
real API enables it. Anonymous web rendering and requests receive separate tests.

Deploy to QA and validate anonymous responses before production promotion. The
legacy gated serializer remains available to internal callers, with default-false
`ServerOptions.InPlayPublicRead`; production composition opts in explicitly.
Making these reads public does not change other subscription prices or benefits.
