Design reference · 15 Oct 2026

Components & ads

Fixes from the review of the live site: team crests everywhere, the favourite button, in-feed native ads and the featured ACCA grid.

Team crest

Every team name is shown with its crest: in prediction rows, Best Bets, ACCA legs, the Builder (matches and ticket), in-play rows, results and the match page.

AR16pxAR20pxAR24px
16:30Real logo (from the feed)CTCaernarfon Town · fallback
  • Use the team logo URL from the fixtures feed, served from our own image cache (never hot-linked to the provider, never a provider name in the UI).
  • Sizes: 16px dense lists / ACCA legs on mobile · 20px prediction rows · 24px cards · 32px+ match headers. Always a fixed box (width and height set) so nothing shifts while it loads.
  • Missing or broken logo → initials shield (first letters of the first and last word, colour from the team name). Same size as the logo.
  • alt="" and aria-hidden on the image; the team name next to it is the accessible label.
  • Two teams in a row are stacked (home over away), each with its crest, so long names are not cut to “Penyb…”.

Favourite button

Fixes the oversized red boxes on the England / Premier League headers and on every row.

  • Icon-only ghost button: no border, no background. Heart outline in --faint when off; filled --fav (#FF7A8A dark · #D23B54 light) when on. 18px icon in a 44×44 hit area (36×36 in league headers).
  • Where: the end of each match row, outside the row link (a button can’t sit inside a link), and on the right of each league sub-header (“follow league”).
  • Not on country headers. A country is a grouping, not something to follow. The count (“8 predictions”) stays where it is, and nothing overlaps it.
  • aria-pressed + label “Add Airbus UK v Trefelin to favourites” / “Remove … from favourites”. Signed-out users get the sign-in prompt on tap.
  • Favourite state never changes the row’s text colour (the blue hover text on the live site is off-system; hover uses --accent-ink).

  • Width = the content column (desktop 8/12 columns, tablet and mobile full width minus 16px gutters). Never a fixed 300–400px box inside a wide column.
  • Native widget layout by container width: ≥ 600px → 4 tiles in one row · 400–599px → 2×2 · < 400px → list of 3 (thumbnail left, title right). Minimum tile width 160px.
  • Titles: 2 lines max with ellipsis; word-break: normal; overflow-wrap: normal; hyphens: none, so no word is ever split.
  • Theme: container uses --surface, text --text; request the provider’s dark template when data-theme="dark" (or style the widget with our CSS variables). Label “Sponsored”.
  • If the widget can’t fit or doesn’t fill: fall back to a display unit (728×90 desktop / 300×250 mobile), or collapse the slot completely.
  • Position: after the 5th row in ranked lists (Best Bets), after the first group in grouped lists. Never between a header and its first row; at most one in-feed unit per 8 rows.
