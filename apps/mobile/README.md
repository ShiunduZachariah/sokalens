# Flutter Mobile App Boundary

Phase 1 reserves the mobile app boundary at `apps/mobile`.

The final app name is undecided and must stay configurable.

The Flutter app should be scaffolded after the shared API contracts stabilize. It will use the Go API for auth, Match Analysis, Match Insights, Favorites, Analysis Watchlist, Analysis Alerts, push preferences, subscriptions, no-ads behavior, Multi-Match Builder, and server-driven restricted-feature config.

Mobile-facing title, listing, navigation, screenshots, and primary UI must use analysis language. Launch mobile without partner CTAs, affiliate links, restricted ad categories, or financial outcome calculators.
