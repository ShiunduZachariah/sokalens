# SokaLens brand assets

The primary direction is **Concept 01: Insight Lens**. It combines a football-analysis lens with a compact statistical bar chart, which stays legible at favicon size and avoids generic betting imagery.

Assets:

- `concept-01-insight-lens.svg`: recommended primary concept.
- `concept-02-pitch-pulse.svg`: pitch and momentum-chart alternative.
- `concept-03-momentum-path.svg`: abstract forecast-path alternative.
- `sokalens-primary-on-light.svg`: full primary logo for light surfaces.
- `sokalens-primary-on-dark.svg`: full primary logo on graphite.
- `sokalens-mark-on-light.svg`: transparent icon-only mark for light surfaces.
- `sokalens-mark-on-dark.svg`: icon-only mark on graphite.
- `sokalens-app-icon.svg`: square favicon/app icon source.

All files are editable SVGs. Their `<title>` and `<desc>` elements make the standalone assets understandable to assistive technology. When an asset is used next to visible text, render it as decorative to avoid announcing the brand twice.
